## 2. 첫 DM 템플릿 (영어)

원칙: 짧게, 무엇을 주는지와 조건을 첫 메시지에서 밝힌다. 결과 칭찬을 요구하지 않는다. 팔로워에게 효과가 보장된다는 말, 크리에이터의 취향을 짐작하는 말 금지.

**DM 1 (코드만 제공)**

> Hi [name], I'm [your name], I make Fatesaid, an app that reads Korean saju (a birth chart based on four pillars) in plain English. I like how you talk about [specific recent video topic].
>
> I'd like to give you a free full report from the app, no strings. If you try it and want to talk about it in a video, great. If not, no problem. Any opinion you share is yours, good or bad.
>
> One thing: if you post about it, it needs a clear "ad" or "free product" label, because you received it for free. Details below if you're interested.
>
> Want me to send a code?

**DM 2 (영상 1건 대가 제안, 현금 포함)**

> Hi [name], I'm [your name] from Fatesaid, a Korean saju app. I'd love to pay you $[amount] for one short video about it, plus a free report for you to try first.
>
> You decide how to show it and what to say. I'll never ask you to say something you don't think. The video needs a clear paid-partnership label.
>
> Rates are tight on my side, so tell me yours if this doesn't fit.

**답장이 온 뒤 (코드 전달 메시지)**

> Thanks! Here's your code: [CODE]. In the app: Settings → "Have a code?" → enter it. [방식이 확정되면 경로를 맞춘다] It unlocks one report of your choice for [30] days.
>
> Reminder: label any post that mentions it as an ad or a free product. No script, no deadline, no required wording.

**후속 (답이 없을 때, 1회만)**

> Hi [name], just checking in once. No worries if it's not a fit. Thanks for your time.

보내지 않는 것: 반복 독촉, 단체 복붙 DM에 이름 칸 비움, "guaranteed views", "your followers will love it".

## 3. 협찬 표기 안내 문구

FTC 안내([Disclosures 101 for Social Media Influencers](https://www.ftc.gov/business-guidance/resources/disclosures-101-social-media-influencers)) 요지:
- 무료 제품도 표기 대상이다. 영상 설명란만이 아니라 **영상 안(화면 자막과 말)** 에 표기한다. 프로필·더보기·해시태그 더미 속은 놓치기 쉽다.
- "ad", "advertisement", "sponsored", "free product" 같은 분명한 말을 쓴다. "sp", "collab", "thanks", "ambassador"만 쓰는 것은 모호하다. 해시태그 `#ad`는 필수는 아니지만 쓸 수 있다.
- 표기는 영상과 같은 언어로.
- 표기 책임은 크리에이터에게 있다고 안내한다. 브랜드 쪽 책임 여부는 위 페이지에서 확인하지 못했다 `(미확인)`. 안전하게 우리도 표기를 요청하고, 표기를 안 한 게시물은 올리지 말 것을 부탁한다.
- 플랫폼의 브랜드 콘텐츠 설정이 있으면 켜도록 권한다. 다만 도구만으로 충분하지 않을 수 있다(FTC 같은 페이지). 틱톡·인스타 설정 위치는 확인하지 못했다 `(미확인)`.
- 이 키트는 법률 자문이 아니다. 미국 외 크리에이터는 해당국 규정이 다를 수 있다 `(미확인)`.

**크리에이터에게 보내는 한 장 안내(영어)**

> **Disclosure note (please read)**
> You received this report for free (and/or payment). That counts as a material connection, so any post about Fatesaid should say so clearly.
> - Put it in the video itself: on-screen text plus a spoken line, e.g. "I got this app free from Fatesaid" or "Ad: free report from Fatesaid".
> - Use plain words: "ad", "sponsored", "free product". Please avoid only "collab" or "sp".
> - Keep it visible for the whole first few seconds, not only in the caption.
> - You may use the platform's paid-partnership label too.
> - This isn't legal advice; you're responsible for your own disclosures.

## 4. 자유 의견 원칙 (후기·성과 조작 금지)

- 크리에이터에게 **좋은 평가, 별점, 수치, 특정 문구를 요구하지 않는다.** 사전 대본·승인 요구도 하지 않는다. 사실 오류(기능, 가격)만 정정 요청 가능.
- 부정적인 의견도 환영한다고 DM에 적는다.
- 크리에이터 영상의 댓글·좋아요를 사거나 가짜 계정으로 올리지 않는다.
- 우리 쪽 광고·게시에서 크리에이터 영상을 증폭할 때는 그 크리에이터의 허락과 사용권(Spark Ads 코드 등) 범위를 따른다(TODO 9).
- 크리에이터가 쓰는 말에 "정확하다/적중/예측" 같은 표현이 있으면 증폭하지 않는다(우리 공통 규칙). 크리에이터에게는 이 표현을 쓰지 말라고 요구하지 않고, 우리가 올리지 않을 뿐이다.
- 코드 받고 안 올려도 불이익이 없다. 올리지 않는 사람에게 다시 요구하지 않는다.

## 5. 코드 전달 방식 (추천안 (c) 승인·구현 후 기준)

| 항목 | 값 | 비고 |
|---|---|---|
| 코드 수 | 크리에이터당 1개(심층 리포트 1건) | 수량·만료는 사용자 결정(`CODES.md` 4장) |
| 만료 | 발급 후 30일 `(제안)` | 코드 입력창이 열려 있을 때만 의미 |
| 라벨 | `seed_a01`, `seed_a02`… | 크리에이터 신원 대신 라벨만 기록 |
| 전달 | 해당 크리에이터와의 DM에만, 한 번에 한 개 | 공개 게시 금지를 부탁 |
| 입력 경로 | 앱 설정 → "코드가 있나요?" | 구현 시 확정 |
| 안 되는 것 | 궁합 리포트 | 소모성이라 권한 없음 |

방식이 (a)/(b)로 바뀌면: 리딤 링크 또는 스토어 입력으로 안내문만 바꾼다.

## 6. 성과 기록표 (시트에 복사해서 사용)

| 라벨 | 계정 | 플랫폼 | 팔로워 | 최근 10개 중앙값 조회 | DM 발송일 | 답장 | 코드 발급일 | 코드 사용일 | 게시일 | 광고 표기 확인 | 영상 URL | 조회 7일 | 저장·공유 | 프로필 링크 클릭 | utm_content | 비용($) | 메모 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| seed_a01 | | | | | | | | | | 예/아니오 | | | | | | | |

기록 규칙:
- 링크는 크리에이터별로 `utm_source=<platform>&utm_medium=seed&utm_campaign=seeding&utm_content=<라벨>` 형태(허용 값은 소문자 영숫자·`_-` 40자 이하, `lib/eventSchema.ts`). 프로필 링크 하나로 나눌 수 없으면 영상별 링크를 설명란이나 크리에이터 프로필에 달도록 부탁한다 `(미확인: 크리에이터가 따를지)`.
- 사용 유무는 서버 쪽 `seed_codes` 기록으로, 성과는 `events`의 utm 값과 플랫폼 분석으로 본다.
- 광고 표기를 안 한 게시물은 "아니오"로 적고, 크리에이터에게 수정을 정중히 요청한다. 증폭에서 제외.
- 판단은 4주 뒤 한 번에: 비용 대비 유형 카드 도달 수(utm), 이후 설치·결제.
