## 2. 공통 패턴 5개
1. **밈(Meme)과 공감대 활용:** 소셜 미디어에서 친구를 태그하거나 스토리에 재공유하기 좋은 형태의 텍스트 이미지를 적극적으로 사용.
2. **특정 별자리 호명:** 특정 그룹을 호명하여 해당 그룹의 높은 클릭률을 유도.
3. **인간관계와 궁합 강조:** 연애, 친구 관계, 직장 동료와의 상호작용 등 타인과의 관계 역학을 풀어내는 소재 비중이 높음.
4. **네이티브 UI 모방:** 스마트폰 잠금 화면의 푸시 알림이나 문자 메시지 대화창 형태를 광고 크리에이티브로 사용.
5. **숨겨진 패턴 발견:** 표면적인 성격이 아닌, 깊은 심리적 패턴이나 타이밍을 알려준다는 접근 방식.

## 3. 우리가 따라 하면 안 되는 것 (공통 지침 위반)
* **개인 특성 짐작 (Rule 4):** "당신은 불안형 애착인가요?" 같이 보는 사람의 상태를 짐작하는 2인칭 문구 (Meta 개인 특성 정책 위반).
* **부정적 예언 (Rule 2):** "돈을 잃는다", "나쁜 궁합" 같은 단정적 부정 예언 및 공포 마케팅.
* **의료/심리치료 효과 약속 (Rule 5):** 진단이나 치료 도구인 것처럼 포장하는 행위.
* **가짜 UI (공통 패턴 4번):** 푸시 알림, 문자창, 재생 버튼처럼 광고 안에서 실제로 동작하지 않는 UI를 흉내 내는 것. 메타 정책상 금지다.
* **실존 인물 노출:** 유형 카드의 유명인 이름이 광고에 나오면 보증처럼 보인다. 촬영할 때 가리거나 잘라 낸다.

## 4. Fatesaid 차별 각도 3개
1. **한국 사주라는 낯섦과 실제 천문 계산 (호기심/신뢰도):** 태어난 순간의 달력(연·월·일·시)을 천문 데이터로 실제 계산한다는 점. 서양 점성술과 비교하거나 깎아내리지 않는다. 랜딩 카드는 도시를 받지 않으므로 광고에서 "출생 도시", "정밀한"은 쓰지 않는다.
2. **50가지 사주 유형 (공유욕/정체성):** 12개가 아닌, 50가지 유형으로 분류되는 사주 시스템의 독특함과 공유하고 싶은 카드 시각화.
3. **고대의 지혜와 현대 심리학의 결합 (자기이해):** 단순 점술이 아니라 심리검사 모듈과 AI 상담이 결합된 입체적인 리포트 도구임을 강조. **앱 전용 기능이므로 출시 뒤 설치 캠페인에서 쓴다.**
