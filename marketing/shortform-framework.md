# 경쟁 숏폼 분석 기준 (2026-10-28, 사용자 확정: 설치 기준, 그룹 4개 전부)

이전 조사(`hook-analysis.md`, `reference-videos.md`, 2026-10-20)는 검색 결과 약 35개를 화면으로만 봤고 소리·댓글·계정 평균과의 비교가 없었다. 이 문서는 다음 분석부터 쓸 **고정 기준**이다.

목적: 조회수가 큰 영상이 아니라 **(1) 평소보다 크게 퍼졌고 (2) 설치로 이어지는 구조이며 (3) 우리가 규칙 안에서 20편 넘게 반복해 만들 수 있는 형식**을 찾는다.

## 1. 표본: 무엇을 모으나
| 그룹 | 계정 예 | 왜 |
|---|---|---|
| G1 직접 경쟁 (영어권 사주) | Palja, Dain Saju Letter, Sophie Saju World, Hayan Lee, Liry Onni, Jewel SJPJ | 같은 소재를 영어권에 파는 사람들. 대부분 조회가 작아 "무엇이 안 되는지"도 보인다 |
| G2 점성술 앱 | Co-Star, The Pattern, Nebula, CHANI, Sanctuary | 우리 사용자가 이미 쓰는 앱(PRODUCT.md). 영어권 운세 숏폼의 기준선 |
| G3 심리·관계 앱 | Olively, 16Personalities, 애착 유형 계정 | 우리 12개 심리 검사 모듈과 같은 수요 |
| G4 유료 광고 | 위 계정들의 Meta 광고 라이브러리, TikTok Creative Center Top Ads | **오래 돌아가는 광고 = 설치가 나는 소재**라는 가장 직접적인 신호 |

- 계정당 **조회 상위 10개 + 최근 10개**. 상위만 보면 생존 편향(같은 형식으로 망한 영상은 못 본다).
- 플랫폼은 TikTok 먼저, 같은 영상이 Reels·Shorts에도 있으면 같이 적는다.
- G4는 30일 넘게 집행 중인 광고만 "검증된 소재"로 표시한다.

## 2. 퍼진 정도: 숫자 기준
조회수 그대로는 계정 크기 차이를 못 걸러 낸다. 아래 파생 지표를 쓴다.

| 지표 | 계산 | 판단 |
|---|---|---|
| **이상치 배수** | 영상 조회 ÷ 그 계정 최근 20개 조회 중앙값 | 5배 이상 = 바이럴. 핵심 지표 |
| 공유율 | 공유 ÷ 조회 | 새 사람에게 퍼지는 힘. 앱 확산에 가장 중요 |
| 저장율 | 저장 ÷ 조회 | 다시 보고 싶은 정보·결과형인지 |
| 댓글율 | 댓글 ÷ 조회 | 참여 장치가 있는지 (내용은 4장) |
| 좋아요율 | 좋아요 ÷ 조회 | 참고만 |

중요도: 공유 > 저장 > 댓글(내용) > 좋아요.

예: Olively "pov: unhinged" 영상은 조회 420만, 최근 영상 조회가 약 1천이라 **이상치 배수 약 4,000배**이고 공유율 0.03%, 저장율 0.08%다. 거의 모든 영상이 1천 안팎에 머물고 몇 개만 터지는 계정이라는 뜻이고, 그래서 **많이 올리는 전략**이 맞는다는 점도 숫자로 확인된다.

## 3. 왜 퍼졌나: 영상 해부 항목
| 구간 | 기록할 것 |
|---|---|
| 훅 0~3초 | 문장 유형(POV 상황 / 목록 / Part N 연재 / 날짜 뉴스 / 질문 / 도구 시연 / 결과 공개), 첫 화면 종류(얼굴 / 앱 UI / 글자 카드 / 실사 장면), 첫 화면 자막 단어 수 |
| 형식 | 화면 녹화 / 이미지+자막 / 말하는 얼굴·그린스크린 / 인터뷰 / 상황극 |
| 속도 | 길이(초), 컷 수, 초당 컷 (PySceneDetect) |
| 소리 | 유행 음원 / 원본 음성 / AI 음성 / 무음+자막, 말한 내용 전사 (whisper) |
| 앱 노출 | 앱 화면이 처음 나오는 초, 앱 이름이 나오는 초, CTA 종류(link in bio / 댓글 / 없음) |
| 참여 장치 | 연재 번호, 정체성 라벨("I'm a ___"), 공유 유도("send this to"), 저장 유도(목록·참고용), 댓글 놀이(유형 맞히기) |

## 4. 누구에게 노출되나
TikTok은 팔로워보다 **주제(관심사)**로 보여 준다. 그래서 "누가 봤나"는 댓글과 주제로 추정한다.

- 댓글 50개 표본(브라우저에서 읽음): 언어 비율(EN/ES/KO/기타), 자기 동일시("this is so me") 비율, **친구 태그(@) 비율 = 공유 신호**, **"what app" / 앱 이름 언급 비율 = 설치 의도 신호**.
- 주제 묶음: 연애·관계 / 자기 이해 / K-culture / 영성·점성 / 웰빙.
- 해시태그와 음원.
- 한계: 연령·지역 직접 데이터는 없다. TikTok Creative Center의 광고·해시태그 화면이 연령대·국가를 일부 보여 주므로 G4에서 보완한다.

## 5. 설치로 이어지나
- 제품 자체가 콘텐츠인가(앱 화면 시연), 브랜드만 있는 콘텐츠인가(Co-Star 거리 인터뷰처럼 앱이 안 나옴).
- 댓글의 "what app" 비율(4장).
- 같은 소재를 광고로도 돌리는가(G4).

## 6. 우리 앱에 유리한가: 점수표
각 축 0~2점. **규칙 축이 0이면 다른 점수와 상관없이 탈락.**

| 축 | 0 | 1 | 2 |
|---|---|---|---|
| 규칙 (게이트) | 금지 표현 필요(예언·정확도 주장, 부정 단정, 댓글에 생일, 가짜 후기, 가짜 긴급) | 문장을 바꾸면 가능 | 그대로 가능 |
| 확산 | 이상치 배수 2배 미만 | 2~5배 | 5배 이상이거나 공유율이 그 계정 상위 |
| 설치 연결 | 앱이 안 나오고 "what app" 댓글도 없음 | 둘 중 하나 | 앱 화면 시연 + 앱 질문 댓글 |
| 재현 | 얼굴 출연·촬영·우리에게 없는 기능 필요 | 일부 새로 만들어야 함 | 지금 자산으로 가능(유형 카드 50, 궁합, 도메인 카드, Year Wrapped, 앱 화면 녹화, AI 음성) |
| 반복 | 한 번 쓰는 아이디어 | 5~10편 | 같은 틀로 20편 이상(유형 50개, 일간 10개, 모듈 12개, 절기 24개) |

성공 기준은 **설치**다(사용자 결정 2026-10-28). 그래서 동점이면 설치 연결 점수가 높은 쪽, 그리고 G4에서 30일 넘게 집행 중인 광고와 같은 형식인 쪽을 앞에 둔다.

**합계 8점 이상(10점 만점)이면 시험 후보**, 그중 상위 3개 형식을 2주 시험(`video-kit.md` 운영 규칙)에 넣는다.

## 7. 도구 (2026-10-28 설치)
| 도구 | 쓰임 | 위치 |
|---|---|---|
| yt-dlp 2026.10.21 (brew) | 영상·메타데이터(조회·좋아요·공유·저장·음원·길이) 받기, 프로필 영상 목록과 조회수 | `yt-dlp` |
| whisper.cpp (brew) + small 모델 | 음성 전사(언어 자동 감지) | `whisper-cli -m ~/.local/share/whisper-models/ggml-small.bin` |
| PySceneDetect 0.7.2 | 컷 수·컷 시점 | `~/.local/share/shortform-venv/bin/scenedetect` |
| ffmpeg (기존) | 오디오 추출, 0·1·2·3초 프레임 | `ffmpeg` |
| Chrome (로그인됨) | 댓글 읽기, Meta 광고 라이브러리, Creative Center | Claude in Chrome |

확인한 것: TikTok 영상 1개 받기·메타데이터·전사·컷 분석 성공, 프로필 목록과 조회수 받기 성공. **TikTok 댓글은 yt-dlp로 0개**라서 브라우저로 읽는다. 많이 받으면 TikTok이 막을 수 있어 계정당 20개로 제한한다. 받은 영상은 분석용으로만 쓰고 다시 올리지 않는다.
