# 작업 지시서 18: 공개 웹 페이지 점검 (읽기 전용)

## 목표
https://fatesaidapp.com 의 공개 페이지(랜딩 /, /en, /es, 계산기, /guides 및 가이드 글 3개)를 열어 점검하고 보고한다. 코드는 수정하지 않는다.

## 점검 항목
- 깨진 내부 링크(404), 빈 화면, 콘솔 오류
- en/es 페이지에 한국어가 섞여 나오는지
- 오탈자, 어색한 문장
- 모바일 폭(375px)에서 가로 스크롤이 생기는지

## 제약
- 파일을 수정하지 않는다. 로그인이나 결제는 하지 않는다. 저장소의 .env*, 키, 소스 코드는 읽지 않는다.

## 완료 조건
- 페이지별 표(URL, 결과, 문제점)와 문제 목록을 마크다운으로 출력
